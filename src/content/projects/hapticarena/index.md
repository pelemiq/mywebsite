### Description

Edge Haptic Arena renders the game of dodgeball as a AAA virtual reality game in terms of graphics and interaction. The video game does not run on the headsets but is rendered in the cloud using Nvidia CloudXR servers and reaches the players in real-time, utilizing the VR compositor to prevent dizziness.

To increase game immersion, users wear a haptic vest that generates feedback for each shot received, pushing you at the exact location of the hit.

This project was showcased during the Barcelona´s 2024 MWC, with more than 200 players during the event

### Role
I led the programming team in developing the technical solutions needed to realize the project, including gameplay development, game architecture, and architecting the cloud rendering solution.

### Tools and Technologies

- Unreal Engine 5.1
- Cloud XR Rendering
- Haptic feedback from a third party vest, using its API
- C++
- Multiplayer
