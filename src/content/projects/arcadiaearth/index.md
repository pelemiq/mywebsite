### Description


Arcadia Earth is an educational application aimed at extending classrooms across the United States. It is built in Unreal Engine for the Apple iPad as the target platform.

The application was designed to maximize the hardware's capabilities, with user-created building blocks and utilizing 3D graphics with dynamic lighting and a high level of detail.

The multiplayer infrastructure was built upon AWS GameLift to ensure its scalability for session hosting.
